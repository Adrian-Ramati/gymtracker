# Notas para el análisis semanal

Este archivo se incluye en cada informe semanal como contexto para la IA.
Edítalo libremente cuando quieras corregir el enfoque, avisar de una molestia,
pedir que no repita un consejo, cambiar el tono, etc. Los cambios se aplican
desde el próximo informe que se genere — no hace falta tocar código.

Ejemplos de cosas que puedes escribir aquí:
- "No repitas el mismo consejo sobre el press banca cada semana si ya lo apliqué."
- "Soy sensible al hombro derecho, ten cuidado al recomendar ejercicios de empuje overhead."
- "Prefiero un tono directo y sin rodeos, sin frases de ánimo genéricas."
- "Prioriza siempre volumen de espalda alta, es mi punto débil."
